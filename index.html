WMT Pay Period Printer

Click once on Worksheet View. This loads every day in the pay period and turns them into one printable file you can save as a PDF.

1. Install the bookmark

Show your bookmarks bar (Ctrl + Shift + B), then drag this button onto it:

Print Pay Period

Chrome or Edge. If drag-and-drop is blocked, copy the address and paste it as a new bookmark’s URL.

2. Run it on Worksheet View

  1. Log into WMT Scheduler.
  2. Open Views → Work Sheet View.
  3. Click any date in the pay period you want (the row of dates near the top).
  4. Click the Print Pay Period bookmark.
  5. Wait while each day loads — stay on that tab. If this area has an OS schedule, that is loaded too.
  6. A separate preview window opens so a WMT refresh does not close it. Allow pop-ups for wmtscheduler.faa.gov if it does not appear.
  7. Click Print in that window — print it, or pick Save as PDF. If WMT refreshed the overlay, click the bookmark again to restore the last preview.

What you get

  • One printout covering the whole pay period (usually 14 days).
  • One page per day. OS names go in the Sup column on the area sheet, and OS requests are merged in.
  • That day’s shifts, who is working them, and the request tables.

This only reads pages you can already open. It does not change the schedule. Close the overlay with Esc to return to WMT. The preview window stays open if WMT refreshes.

Local tool for Worksheet View on wmtscheduler.faa.gov. No install, no internet required after you save this folder.
